## 一、产品一句话定位

**MyDiary 是一款"AI 驱动的个人生活记录与知识库应用"**。用户写日记 → AI 自动分类归档 → 沉淀成结构化知识库 → 反过来 AI 用知识库回答用户的问题。

核心循环：**写 → 沉淀 → 回忆 → 再写**

## 三、功能模块清单（按用户使用顺序组织）

### 模块 0：账号与身份

> **入口**：登录页 / 注册页 / 个人中心
> **状态**：✅ 已上线

| 功能 | 说明 | 业务逻辑 |
|---|---|---|
| 邮箱验证码登录 | 用户输入邮箱 → 收到 6 位验证码 → 登录/注册合并（没有账号就自动创建） | 验证码存 KV，5 分钟过期；密码存 D1，加盐哈希 |
| 修改密码 | 已登录用户改密码 | 需验证旧密码 |
| 个人信息 | 昵称、头像、bio、身份、兴趣、生日 | 首次登录后有 onboarding 引导填写 |
| 记忆系统 | AI 自动从日记问答对话中提取用户偏好/事实 | 存 D1 `memories` 表，AI 回答时自动用上 |

### 模块 1：写日记（核心主链路）

> **入口**：首页月历 + 底部导航「✍️」按钮 + 语音快记
> **状态**：✅ 已上线

这是整个产品的**数据源头**——所有子模块和知识库的内容，都来自用户写的日记。

#### 1.1 日记编辑器（EditorPage）

用户点写日记 → 进入编辑器。编辑器是**模板驱动**的。

| 功能 | 说明 | 业务逻辑 |
|---|---|---|
| 模板选择 | 10 个内置模板 + 用户自建模板 | 不同模板有不同的 blocks 类型和 AI prompt |
| Blocks 编辑 | 日记由多个 block 组成：标题、正文、待办、数字、分割线、图片、音频 | 用户可以自由组合/重排 |
| AI 润色/填充 | 选好模板后，AI 根据模板 prompt 把用户输入自动结构化成 blocks | 主 AI 场景之一，失败时有规则降级 |
| 心情标签 | 12 种预设心情（开心/平静/焦虑/感恩...） | 每个模板可配不同心情 |
| 标签系统 | 用户自定义标签（#旅行 #读书 #感恩） | 可以给日记打多个标签 |
| 地理位置 | GPS 或手动选地点 | 可选 |
| 天气 | 根据日期+位置从服务端获取 | 可选 |
| 保存 | 日记保存到 D1 | 自动标记所属日期、模板、心情、标签 |
| 软删除 | 保存到回收站（30 天后自动清理） | 用户可恢复 / 彻底删除 / 批量操作 |

#### 1.2 模板体系

| 内置模板 | 说明 | blocks 特点 |
|---|---|---|
| 📖 通用日记 | 自由写随笔 | 标题 + 正文 + 可选任何 block |
| 💼 记账 | 收入/支出流水 | 数字 block（金额+分类+方向）+ 备注 |
| 🚩 计划 | 待办清单 | checkbox block（勾选状态）+ 截止日期 |
| 🚴 运动 | 跑步/健身/瑜伽 | 数字 block（时长/距离/配速） |
| 📚 读书笔记 | 书的摘录和感想 | heading + quote + text 混合 |
| 🙏 感恩 | 感恩三件事 | 3 个 text block（固定结构） |
| 🏥 健康 | 身体状况记录 | checkbox + number（体重/血压/头痛程度） |
| 🏆 里程碑 | 人生重要时刻 | 类型（固定日期/起点/倒计时）+ 标题 |
| ✈️ 旅行 | 旅行日记 | 日期 + 地点 + 感受 + 开销 |
| 🎂 纪念 | 生日/周年 | 类型 + 日期 + 标题 |
| 🍳 美食 | 吃了什么 | 店名 + 菜品 + 体验 + 评分 |
| 🎬 观影 | 电影/剧集笔记 | 标题 + 感想 + 评分 + 金句 |

#### 1.3 语音快记（VoiceQuickEntry）

**纯前端功能**，不经过 Worker。

| 功能 | 说明 | 业务逻辑 |
|---|---|---|
| Web Speech API 录音 | 浏览器原生语音识别 | 支持 Chrome 桌面版、Android Chrome；**iOS Safari 不支持、Android WebView 空壳** |
| 意图识别 | AI 判断这段话该用哪个模板 | detectTemplate() → Agnes AI 直连 → 规则匹配降级 |
| AI 润色 | 确认模板后，AI 把录音转写结构化 | polishTranscript() → Agnes AI 直连 → 规则模板降级 |
| 打字输入降级 | 语音不行时用户可以直接打字 | 手动输入 → 同样调 AI 意图识别 |
| 错误提示 | 网络差 / 没听清 / 权限不足 → 明确中文提示 | 2026-10-10 新增，之前静默吞掉 |

#### 1.4 每日一句话摘要（StreakBadge）

| 功能 | 说明 | 业务逻辑 |
|---|---|---|
| 连签徽章 | 首页顶部显示连续写日记天数 | 每日自动判断，今天写过就+1 |
| 每日文艺摘要 | AI 把当天日记浓缩成一句 20-28 字的文艺总结 | 直连 Agnes AI，失败时规则降级（返回模板标题复述） |
| 历史总结 | 点击徽章可看"最长连签纪录" | 从 D1 查询历史 streak |

### 模块 4：知识库（Wiki v4）

> **入口**：首页 Tab 切换 / 个人中心
> **状态**：✅ 已上线

**MyDiary 的杀手级功能**——把分散的日记和资料沉淀成结构化知识。

#### 4.1 知识库本体

| 功能 | 说明 |
|---|---|
| 多知识库 | 用户可以创建多个知识库（如"运维工作支撑"、"旅行足迹"、"读书笔记"） |
| 官方预设 | 一键从预设创建（IT运维、旅行、读书、美食、感悟...） |
| 分类（Categories） | 每个 KB 下的子文件夹，每个分类可选模板 |
| 资料（Sources） | 原始输入：日记、手动输入文本、上传文件 |
| 页面（Pages） | AI 把资料结构化处理后的产物，带向量可搜索 |
| 汇入（Ingest） | 把资料 → AI 结构化 → 生成页面，是整个知识库的核心操作 |

#### 4.2 AI 在知识库里的作用

| AI 场景 | 模型 | 说明 |
|---|---|---|
| **资料汇入** | DeepSeek V4 Flash | 把日记/文本抽成人物/地点/事件/结构化页面 |
| **实体生成** | DeepSeek V4 Flash | 自动生成人物卡片（是谁、和谁什么关系） |
| **向量嵌入** | Workers AI bge-m3 | 给页面生成向量，支持语义搜索 |
| **知识库问答** | Agnes（主）/ Workers AI（fallback） | "我运维工作库帮我找那篇导数SQL" |
| **AI 起标题** | DeepSeek V4 Flash | 给新资料起个好标题 |
| **模板匹配评估** | DeepSeek V4 Flash | 判断一段资料该归到哪个分类 |

#### 4.3 知识库 AI 问答（Wiki Q&A）

| 功能 | 说明 |
|---|---|
| RAG 检索 | 用户提问 → 向量搜索 + 关键词搜索 → Reranker 精排 |
| 联网搜索 | 可开关——AI 回答时能不能用自身常识补充 |
| 来源标注 | AI 回答后面列出参考了知识库的哪些页面 |
| 对话历史 | 多轮对话，支持追问 |

## 四、模块之间的关系

### 4.1 数据流

```
用户写日记（模块 1）
    │
    ├─→ 自动归档到各子模块（模块 3：纪念日/计划/记账/书柜/标签）
    │
    ├─→ 用户手动"存入知识库"（模块 4）
    │       └─→ AI 汇入 → 生成结构化页面 → 向量嵌入
    │
    └─→ AI 问答（模块 5）
            ├─→ 查日记（D1）
            ├─→ 查知识库（D1 + 向量）
            └─→ 用记忆（memories 表）
```

### 4.3 哪些模块是"自动"的

| 自动行为 | 触发条件 | 说清楚 |
|---|---|---|
| 日记自动归档到子模块 | 保存日记时 | 根据模板类型自动归类（记账模板自动进记账统计） |
| AI 每日摘要 | 每日首次打开首页 | 调 Agnes AI，失败降级 |
| AI 记忆提取 | 每次 AI 问答后 | 异步，不阻塞主流程 |
| 语音快记意图识别 | 用户录音停止 | 调 Agnes AI，失败降级规则匹配 |
