## 改了什么

| 文件 | 改动 |
|---|---|
| `src/components/BottomDock.tsx` | 底栏改为 **今天 · 回忆 · 🎙️ · 小麦 · 我的**；小麦入口首次显示小红点 |

## 本地运行

```
cd "D:\mydiary code\my-diary"
npm run build      # 先确认能构建（含类型检查）
npm run dev        # 浏览器打开 http://localhost:5173
```
本地前端默认连**测试后端**，用测试账号登录。

## 测试清单

### 底栏
- [ ] 底栏顺序：今天 · 回忆 · 🎙️ · 小麦 · 我的（头像）
- [ ] 手机宽度（开发者工具切到 375px）下 5 个入口不换行、不挤压
- [ ] 小麦入口有小红点；点进小麦后小红点消失，刷新后也不再出现
- [ ] 当前页对应的入口高亮正确：首页→今天，日记列表/书柜→回忆，小麦→小麦，我的→我的
- [ ] 点当前已高亮的入口不会重复跳转

### 回忆
- [ ] 点"回忆"进入时间线（原日记列表）
- [ ] 顶部切换到"书柜"→ 显示书柜；再切回"时间线"
- [ ] 两者之间来回切换后，按返回键**不会**在两者之间来回跳（切换用的是 replace）
- [ ] 书柜里打开一本书、关闭，功能正常

### 小麦
- [ ] 点"小麦"进入独立页面，对话、历史会话、流式输出都正常
- [ ] 日记 / 知识库切换正常
- [ ] 首页顶部只剩三个视图：📅 月历 · 📊 年度回顾 · 🌳 知识库

### 新手引导
- [ ] "我的 → 查看新手指引"，回到首页后引导正常播放
- [ ] 引导里"🕰️ 回忆"和"🌾 小麦"两步能正确高亮底栏对应按钮
- [ ] 没有步骤指向不存在的元素（不会卡住或框到空白处）

### Android（可选，出包后）
- [ ] 底栏在真机上显示正常，安全区没有被遮挡
