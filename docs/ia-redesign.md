# MyDiary 信息架构重设计方案

> 状态：方案稿（2026-11-25），未改代码
> 核心定位：**写给小麦听，它帮你记住生活。**
> 设计原则：导航按用户的意图组织（写 / 回忆 / 问），不按功能模块组织

---

## 一、现状盘点

### 底栏（BottomDock）
`首页（日历） · 书柜 · 🎙️语音 · 日记（列表） · 我的`

### 首页（CalendarPage）内部还有 4 个 Tab
`📅 月历 · 📊 年度回顾 · 🌳 知识库 · 💬 小麦`
并从首页跳出 7 个二级页：胶囊、记账、里程碑、计划、标签、回收站、编辑器

### "我的"（ProfilePage）承载了大量非设置内容
设置（字体/主题/提醒/语音）+ 身份兴趣 + 写作统计 + 模板 + 信纸 + 范本 + 记忆 + 资料 + 知识 + 反馈 + 更新记录

### 问题

| 问题 | 表现 |
|---|---|
| **首页和"日记"重复** | 首页的月历和"日记"列表都是"看日记"，只是视图不同（月历 vs 列表），却占了两个底栏位 |
| **小麦藏得太深** | 产品最大的差异点，却是首页里的第 4 个 Tab |
| **"书柜"概念模糊** | 和"日记"列表界限不清，新用户不理解它是什么 |
| **"我的"是杂物间** | 模板、信纸、范本、记忆、知识、资料都塞在这里，设置反而被淹没 |
| **功能并列，没有主次** | 记账/计划/里程碑/胶囊/倒计时都是一级跳转，和"写日记"同等地位 |
| **知识库术语难懂** | "知识库/实体/汇入/史料/范本"是笔记软件的语言，不是日记用户的语言 |

## 二、新结构

### 底栏：3 个 Tab + 中间语音

```
┌──────────┬──────────┬──────────┬──────────┐
│   今天    │   回忆    │  🎙️ 写    │   小麦    │   我（头像，右上角）
└──────────┴──────────┴──────────┴──────────┘
```

> 备选：如果坚持 4 个底栏位，就是 `今天 · 回忆 · 🎙️ · 小麦 · 我`。
> "我"使用频率低，放右上角头像更合理，底栏留给高频动作。

| Tab | 一句话 | 回答用户的问题 |
|---|---|---|
| **今天** | 写，以及被回应 | "今天想记点什么？" |
| **回忆** | 所有写过的东西，按时间和人找 | "那天发生了什么？关于 TA 我写过什么？" |
| **🎙️ 写** | 语音快记（保持现在的中心强调） | — |
| **小麦** | 和小麦聊天、问日记 | "帮我想想……" |
| **我**（头像） | 设置和数据管理 | "我的账号和数据" |

## 三、各页面详细设计

### 1. 今天（新首页）

自上而下：

```
┌─────────────────────────────────┐
│ 11月25日 周三  ☀️ 12°           │
│ 🔥 连续写了 7 天                 │
├─────────────────────────────────┤
│ [ 今天想记点什么？ ]   🎙️  ✏️   │  ← 写入口（文字 / 语音），最显眼
├─────────────────────────────────┤
│ 今天的日记（已写的卡片）          │
│  └ 🌾 小麦：宝宝五岁了呀……        │  ← 写完后小麦的回应
├─────────────────────────────────┤
│ 📜 那年今日                      │  ← 有才显示
│ ⏳ 还有 128 天：五一回老家         │  ← 倒计时/纪念日，有才显示
│ 🕰️ 有 1 个时光胶囊今天解锁         │  ← 有才显示
│ 📊 本周回顾（周日出现）            │
└─────────────────────────────────┘
```

**原则**：今天页只放"和今天有关"的东西，**没有内容的卡片不显示**。新用户看到的就只有写入口，零干扰。

### 2. 回忆（合并 月历 + 日记列表 + 书柜 + 标签 + 心情）

顶部视图切换 + 筛选：

```
[ 时间线 | 月历 | 书 ]                    🔍
筛选：😊心情  🏷️标签  👤人物  💰记账  🎯计划  🎈纪念日
```

| 视图 | 来源 | 说明 |
|---|---|---|
| **时间线**（默认） | 原 DiaryListPage | 按日期倒序的卡片流 |
| **月历** | 原 CalendarPage 月历 | 心情颜色标在日期上（合并 MoodHeatmap） |
| **书** | 原 BookShelfPage | 把一段时间的日记排成书阅读 / 导出 |

- **记账、计划、里程碑、纪念日、胶囊不再是独立页面**，变成"回忆"里的筛选条件。点"💰记账"筛选时，顶部额外出现本月收支汇总（原 FinancePage 的统计）
- **搜索**（原 SearchBar）放右上角，同时支持关键词和"问小麦"
- **回收站**移到时间线底部 / 筛选菜单里的"已删除"
- **年度回顾**：放在月历视图顶部（"查看 2026 年度回顾 →"），年底在"今天"页推送

### 3. 小麦

原 AiChatView，提升为一级 Tab：

- 默认就是日记问答，**不需要选"日记/知识库"模式**
- 空状态给 3–4 个推荐问题（根据用户数据生成："这个月我心情怎么样？""我上次见爸妈是什么时候？"）
- 引用卡片可点击 → 跳到"回忆"里对应那天
- 顶部入口："🌾 小麦记住的事"（原 ProfilePage 的记忆 Tab），可查看、编辑、删除

### 4. 人物（知识库的替代方案）

把"知识库"重新包装成日记用户能懂的概念：

| 现在叫 | 改叫 | 说明 |
|---|---|---|
| 知识库 / 实体 | **人物**、**地点** | 小麦自动从日记里整理出"宝宝""老婆""老家" |
| 汇入 | （自动，不让用户操作） | 写日记后后台自动归档 |
| 史料 / 资料 / 来源 | （隐藏） | 技术概念不暴露给用户 |
| 范本 | （隐藏或并入模板） | |

入口：**"回忆"里的 👤 人物筛选** → 进入某个人物页，看到：
- 小麦写的一段话（"宝宝今年五岁，最近在学骑车……"）
- 所有提到 TA 的日记（时间线）
- 和 TA 有关的纪念日 / 照片

> 现有的"自定义知识库"（读书笔记、菜谱、旅行攻略）**是另一类用户的需求**。建议：
> - 短期：从主导航移除，放到"我 → 高级 → 笔记本"，保留给已在用的用户
> - 长期：观察使用数据，若使用率低则下线，或拆成独立产品

### 5. 我（右上角头像）

只放"账号和数据"，回归设置页本分：

```
👤 头像 · 昵称 · 写作统计（总篇数 / 字数 / 连续天数）
──────────
✍️ 写作偏好：字体、主题、信纸、模板、语音识别方式
🔔 每日提醒
🌾 小麦记住的事（同小麦页入口）
🔒 隐私与数据：导出全部日记、哪些内容会发给 AI、删除账号
──────────
💬 反馈 · 📋 更新记录 · 📖 新手指引
🔑 修改密码 · 退出登录
```

- **身份 / 兴趣**：只在新手引导里问一次，之后放进"写作偏好"里的二级设置，不在首屏
- **"导出数据 · 即将上线"**：建议优先做掉——对日记产品，这是信任的基础

## 四、新旧对照

| 现在的位置 | 新位置 |
|---|---|
| 底栏 · 首页（日历） | 回忆 → 月历视图 |
| 底栏 · 书柜 | 回忆 → 书视图 |
| 底栏 · 日记（列表） | 回忆 → 时间线视图（默认） |
| 底栏 · 我的 | 右上角头像 |
| 首页 · 📊 年度回顾 | 回忆 → 月历顶部；年底推送到今天 |
| 首页 · 🌳 知识库 | 回忆 → 👤 人物；自定义知识库 → 我 → 高级 |
| 首页 · 💬 小麦 | **底栏 · 小麦** |
| 记账页 /finance | 回忆 → 💰 筛选（带收支汇总） |
| 计划页 /plans | 回忆 → 🎯 筛选；今天页显示今日待办 |
| 里程碑 /milestones | 回忆 → 🎈 筛选；今天页显示倒计时 |
| 时光胶囊 /capsule | 写日记时的一个选项；解锁时出现在今天页 |
| 标签 /tags | 回忆 → 🏷️ 筛选 |
| 回收站 /trash | 回忆 → 筛选菜单 → 已删除 |
| 来源 /sources | 隐藏（知识库内部概念） |
| 我的 · 记忆 Tab | 小麦页顶部 + 我 |
| 我的 · 模板 / 信纸 / 范本 | 我 → 写作偏好 |
| 那年今日（OnThisDay） | 今天页卡片 |
| 心情热力图（MoodHeatmap） | 回忆 → 月历视图的日期着色 |

**路由数量**：13 个一级路由 → 4 个主页面（今天、回忆、小麦、我）+ 编辑器 + 人物详情

## 五、实施分阶段（每阶段都可独立上线）

### 阶段 1：调整底栏，不动页面内部（约 1–2 天）
- 底栏改为 `今天 · 回忆 · 🎙️ · 小麦`，"我"移到右上角头像
- "今天"暂时复用现在的首页月历；"回忆"暂时复用日记列表；"小麦"直接用 AiChatView
- 书柜放进回忆顶部的视图切换
- **风险最低**：只改 BottomDock 和路由，页面组件都不动
- 观察：小麦 Tab 的打开率是否明显上升

### 阶段 2：做"今天"页（约 3–5 天）
- 新建 TodayPage：写入口 + 今日日记 + 那年今日 + 倒计时 + 胶囊解锁
- 配合"写完日记小麦回一句"
- 月历移入回忆

### 阶段 3：回忆页合并 + 筛选（约 1 周）
- 时间线 / 月历 / 书三种视图
- 记账、计划、里程碑、标签、回收站改为筛选条件
- 旧路由（/finance、/plans 等）保留一段时间，重定向到回忆页的对应筛选，避免老用户的书签失效

### 阶段 4：人物页替代知识库（约 1–2 周）
- 复用现有 wiki 的实体抽取能力，只换包装和入口
- 自定义知识库迁到"我 → 高级"

## 六、需要注意的事

1. **老用户的习惯**：阶段 1 上线时加一次性的引导浮层（复用现有 FeatureTour）："小麦现在在这里啦 👇"
2. **Android 返回键**：现在的策略是"关弹窗 → 退一页 → 退出"。Tab 结构改变后，确认根页面判定仍然正确（现在 `/` 是根，改版后今天页是根）
3. **FeatureTour 的锚点**：现在依赖 `tour-dock-home`、`tour-dock-shelf` 等 id，底栏改版需要同步更新引导步骤
4. **数据埋点先行**：改版前先用现有的 `logActivity` 统计各页面的打开次数，改版后对比。特别关注：
   - 记账/计划/里程碑页的使用率 —— 决定它们降级为筛选是否合适
   - 知识库的使用率 —— 决定是否下线
5. **平台差异**：按 AGENTS.md 约定，Web 和 App 的差异只写在 `platform.ts`，导航改版不应引入新的平台判断
