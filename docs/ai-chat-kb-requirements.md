## 一、顶部 Tab 切换行为

### 1.1 切到 📖 日记 Tab
- **会话：** 新建空 diary 会话（每次都是新的）
- **空状态：** 💬 "这是小麦，你的智能助手..." + 建议问题

### 1.2 切到 🌳 知识 Tab（场景A）
- **会话：** 新建空 wiki 会话（每次都是新的）
- **顶部 select 标题：** 「选知识库…」（placeholder 提示，必须能显示出来）
- **下拉选项列表：** 永远固定顺序：
  1. 🆕 + 创建知识库
  2. （已有 KB 列表）
- **聊天区空状态：** 通用引导 "🌳 我是小麦，已接入 N 个知识库，选一个开始提问，或者创建新知识库" + KB 卡片 + 创建按钮

## 二、知识库下拉选择行为

### 2.1 选已有知识库（如"智能家居知识库"）
- **会话：** 新建空 wiki 会话，kb_id=所选 KB（每次都是新的）
- **顶部 select 标题：** 显示 KB 名（如"智能家居知识库"）
- **聊天区空状态：** 该 KB 专属初始界面 "🌳 我在 xxx 知识库里..." + 建议问题

### 2.2 选 🆕 + 创建知识库
- **会话：** 新建空 wiki 会话 + creatingKb="collecting"（每次都是新的）
- **顶部 select 标题：** 显示「🆕 + 创建知识库」（绝对不能显示"选知识库…"！）
- **聊天区空状态：** 创建知识库专属界面（不是通用 KB 列表）

## 三、创建知识库聊天框（独立受限流程）

### 3.1 定位
**正常聊天，但有边界。** 最终目标只有一个：拿到 KB 名称 + 说明 → 跑一条龙创建。
**不是哑巴机器**，可以回答用户关于创建流程的问题、自我介绍等。

### 3.2 必须拿到的两个信息

| 信息 | 对应字段 | 来源 |
|---|---|---|
| **知识库名称** | `kb.title` | 用户输入的第一部分 |
| **说明/用来干嘛的** | `kb.description` | 用户输入的第二部分 |

### 3.3 用户输入处理规则

| 用户输入类型 | 识别特征 | 我的回应 |
|---|---|---|
| 给了 name + desc（逗号/句号分隔） | 两个信息都有 | ✅ 跑一条龙创建 |
| 只给了 name | 只有一段比较长的 | 引导补 desc："收到！名字叫 xxx 对吧？还差：它是干嘛的？" |
| 问流程/规则 | "怎么创建"/"流程"/"如何"/问号 | ✅ **回答流程**（不是哑巴！）："创建知识库很简单，告诉我名字和用途就行，我帮你连分类都分好～" |
| 自我介绍 | "你是谁"/"你是做什么的" | ✅ 回答："我是小麦，专门帮你创建知识库的..." |
| 否定/质疑 | "不是啊"/"不对"/"你理解错了" | 引导回去："好的！你想创建什么样的知识库？告诉我名字和用途就行～" |
| 聊别的/无关内容 | 其他 | 引导回去："我这边只帮你创建知识库，告诉我名字和用途就行～" |

### 3.4 拿到信息后（一条龙流程）

调用顺序：
1. `wikiOptimizeDescription(kbDesc, kbName)` — AI 优化说明
2. `wikiAddKb(kbName, kbDesc)` — 建 KB
3. `wikiAIDesignCategories(title, description)` — AI 设计分类
4. 循环 `wikiAddCategory(kbId, { name, template_key, sort_order })` — 创建分类
5. 回复用户结果（分类列表 + 每个分类的模板）
6. creatingKb 进入 "done"

### 3.5 创建完成后（done 状态）

- creatingKb = "done"
- 用户再说任何事 → "我这边只帮你创建知识库，已经帮你建好啦 ✅ 去「我的 → 知识库」看详情吧～"

## 四、切换行为总标准（重要！）

### 核心原则

**切 tab / 切 KB / 选创建 / 点 + 新建对话 → 每次都是新空会话**

> 右上角的 "+" 按钮（newChat）和切 KB 效果完全一样：不继承当前 KB，每次都是干净的空会话。

### 场景验证

| 操作 | 结果 |
|---|---|
| 🌳 知识 tab → 选智能家居 KB | ✅ 新空会话（智能家居初始界面） |
| 聊了 3 条 | |
| 切到汽车 KB | ✅ **又一个新空会话**（汽车初始界面） |
| 再切回智能家居 | ✅ **又是一个新空会话** ← 干净！不是之前那 3 条 |
| 聊了 3 条 → 点右上角 **+** | ✅ **又一个新空会话** ← 干净！不继承当前 KB |
| 选 🆕 + 创建知识库 | ✅ **新空会话**（创建初始界面） |
| 聊完创建了 KB | |
| 再选 🆕 + 创建知识库 | ✅ **又一个新的创建初始界面** ← 干净！ |

**历史会话只通过侧边栏历史抽屉访问。** 切 KB/tab 不会自动恢复历史。

## 五、历史会话

- 0 条消息的会话 → **不保存**（localStorage 存储时过滤：`sessions.filter(s => s.msgs.length > 0)`）
- 历史抽屉按当前 tab 过滤（📖 只显示 diary，🌳 只显示 wiki）
- wiki 会话按 KB 分组显示
