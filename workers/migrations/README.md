# D1 Migrations

## 编号约定

- `0019_drop_diaries_unique.sql` 与 `0019b_hints_upgrade.sql` 共用 0019 号，
  后者靠 `b` 后缀排在前面那个之后（`_` < `b`，字典序天然正确）。
- **禁止重命名已应用的迁移**：`d1_migrations` 按文件名记录，改名会让已应用变成未应用，
  在存量库上重跑一次（`0019_drop_diaries_unique.sql` 会重建 `diaries` 表，重复执行风险极大）。
- 今后新迁移一律用下一个空号（28、29、...），不要再用 `a/b` 后缀。

## 历史备注

`0010`~`0026` 在 prod/dev 上**没有通过 `wrangler d1 migrations apply` 执行过**——
这些表和列是手工 DDL 建的，`d1_migrations` 里只有 0001~0009 是真跑的。
2026-11-10 第八轮整改后把 0026（0027 之前的）标记为已应用，
新结构变更一律走**下一个编号**（0028+），不再回改已标记的迁移。
